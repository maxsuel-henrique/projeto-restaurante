# 🍽️ Sabor Express

Projeto desenvolvido durante meus estudos de **Python na Alura**.

A ideia foi criar um sistema simples para praticar os conceitos básicos da linguagem, simulando um aplicativo de gerenciamento de restaurantes.

## Funcionalidades

* Cadastrar novos restaurantes
* Listar restaurantes cadastrados
* Ativar ou desativar restaurantes
* Validar opções do menu

## O que pratiquei

Durante o projeto, coloquei em prática:

* Listas e dicionários
* Funções
* `if`, `elif` e `else`
* Laços `for`
* `input()`
* `try/except`
* Manipulação de strings
* Importação de módulos
